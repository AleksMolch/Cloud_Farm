# Checklist публикации

## Перед сборкой

- [ ] Обновлена версия и `version` сохранения при несовместимых изменениях.
- [ ] Все новые цены/таймеры добавлены в JSON, а не в сцены.
- [ ] Нет секретов, токенов и приватных ключей в репозитории.
- [ ] Ассеты не нарушают авторские права.
- [ ] Игра использует только подтверждённые методы Playgama/Yandex SDK.

## Автоматическая проверка

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

- [ ] typecheck без ошибок.
- [ ] все unit-тесты зелёные.
- [ ] production build собирается.
- [ ] `dist/index.html`, `dist/playgama-bridge-config.json` и `dist/assets` на месте.
- [ ] размер JS не превышает лимит платформы; при необходимости включить дополнительное сжатие.

## Ручной smoke-test

- [ ] Игра грузится на desktop Chrome/Safari/Firefox.
- [ ] Игра грузится на мобильном Chrome/Safari в landscape.
- [ ] В портрете показывается rotate hint.
- [ ] Первый сбор пшеницы, первый заказ и первый апгрейд проходятся без тупика.
- [ ] Работают туториальные подсказки и подсветка.
- [ ] Работают заказы, магазин, склад, настройки.
- [ ] Работает покупка моркови, открытие зоны и найм кота.
- [ ] Работает оффлайн-модалка и ×2 rewarded.
- [ ] Отмена rewarded не выдаёт награду.
- [ ] Interstitial не появляется в первые 3 минуты.
- [ ] Сохранение переживает reload.
- [ ] Повреждённое сохранение не ломает игру.
- [ ] Язык ru/en переключается и сохраняется.
- [ ] Звук/музыка отключаются настройками и на время рекламы.
- [ ] При скрытии вкладки игра ставится на паузу, при возврате возобновляется.
- [ ] Нет ошибок в консоли.
- [ ] Нет 404 по ассетам и favicon.

## Playgama

- [ ] В `index.html` подключён актуальный Bridge CDN.
- [ ] `playgama-bridge-config.json` лежит рядом с `index.html`.
- [ ] В конфиге заданы placements: `offline_double`, `speed_up`, `zone_unlocked`, `milestone`.
- [ ] Если нужны platform-specific ID, они добавлены в `platforms.<id>`.
- [ ] `game_ready` вызывается после первого интерактивного кадра.
- [ ] Playgama storage используется как основной механизм сохранения.
- [ ] Rewarded-награда выдаётся только при состоянии `rewarded`.
- [ ] Interstitial вызывается в естественных паузах.
- [ ] Проверено в Playgama sandbox на целевом partner platform.
- [ ] Загружен zip содержимого `dist`, а не папка верхнего уровня.

## Yandex Games (прямая публикация)

- [ ] Билд размещён на домене, где доступен `/sdk.js`.
- [ ] `YaGames.init()` вызывается после загрузки SDK.
- [ ] `LoadingAPI.ready()` вызывается после готовности игры.
- [ ] `GameplayAPI.start/stop()` соответствуют реальному состоянию.
- [ ] Fullscreen/rewarded обрабатывают `onClose`, `onError` и `wasShown === false`.
- [ ] Награда выдаётся только после `onRewarded`.
- [ ] Сохранение использует `ysdk.getStorage()`.
- [ ] Проверено в Yandex Games debug-mode.
- [ ] Заполнены название, описание, иконка, скриншоты, категория, возрастной рейтинг.
- [ ] Добавлена privacy policy, если требуется платформой.
- [ ] Пройдена модерация черновика.

## Ассеты и витрина

- [ ] Иконка игры: парящий остров, мельница, милое животное/кот, голубое небо, золотой урожай, высокий контраст.
- [ ] Скриншот 1: общий вид острова.
- [ ] Скриншот 2: сбор урожая и монеты.
- [ ] Скриншот 3: животные и помощники.
- [ ] Скриншот 4: заказы и производство.
- [ ] Скриншот 5: открытие новой зоны/оффлайн-награда.
- [ ] Название: «Ферма на Облаке» / «Cloud Farm».
- [ ] Короткое описание и теги: farm, idle, tycoon, farming, animals, cozy, clicker, management.
- [ ] Промпты Nano Banana и pipeline из `docs/ASSETS.md` использованы для финального арта.
- [ ] Музыка/SFX заменены или проверены синтезированные.
