# Ферма на Облаке — дизайн MVP

Дата: 2026-11-19  
Статус: принято к реализации  
Источники: `ferma_na_oblake_llm_design_brief.md`, `llm_game_dev_playgama_yandex_prompt.md`, `sdk_compatibility_report_playgama_yandex.md`

## Цель

Собрать компактный data-driven idle farm tycoon для Playgama / Yandex Games / web на Phaser 3 + TypeScript + Vite. Игрок развивает ферму на парящем острове: собирает урожай, выполняет заказы, открывает животных, здания, помощников и получает оффлайн-доход. Первая сессия должна давать законченный цикл за 3–5 минут без тупика.

## Границы MVP

- Один остров, 4 зоны: стартовая поляна, пшеничная терраса, животный дворик, мельничная платформа.
- 4 культуры: пшеница, морковь, клубника, облачная ягода.
- 3 животных: курица (яйцо), корова (молоко), овёшка (шерсть).
- 3 здания: мельница (пшеница → мука), пекарня (мука + яйцо → пирог), молочная будка (молоко → сливки).
- 2 помощника: облачный кот (автосбор одной грядки), пёс (ускоряет животных).
- Заказы, апгрейды до 5 уровня, rewarded-реклама, оффлайн-доход до 2 часов, сохранения, ru/en.
- Не входит: второй остров, prestige, мультиплеер, IAP, лидерборды, 3D, сложная физика.

## Архитектура

- `GameState` — единственный источник игрового прогресса.
- JSON-конфиги: культуры, животные, здания, зоны, заказы, помощники, туториал.
- Сервисы не зависят от Phaser: `EconomyService`, `ProductionService`, `UpgradeService`, `OrderService`, `OfflineProgressService`, `TutorialService`, `SaveService`, `TimeService`, `LocalizationService`, `AudioService`, `AdManager`.
- Сцена Phaser только отображает состояние и отправляет действия в сервисы.
- Платформа скрыта за `PlatformAdapter`:
  - `MockAdapter` — локальная разработка, localStorage, имитация рекламы;
  - `PlaygamaAdapter` — Playgama Bridge JS Core (`bridge.initialize()`, `bridge.storage`, `bridge.advertisement`, `bridge.platform`);
  - `YandexAdapter` — прямой Yandex Games SDK (`YaGames.init()`, `LoadingAPI.ready`, `GameplayAPI`, `adv`, `getStorage`).
- Автовыбор адаптера: Yandex-окружение → Yandex; Playgama с ненулевым platform.id → Playgama; иначе Mock. При публикации в Yandex через Playgama Bridge используется только Playgama-слой.

## Модель времени и производства

- Все таймеры хранятся timestamp-ами, поэтому пауза, фон и оффлайн не ломают производство.
- Грядка: пусто → посадка → рост → сбор. Волшебный кот автоматически собирает и пересаживает закреплённую грядку.
- Животное: после открытия производит циклически; сбор запускает следующий цикл. Пёс сокращает цикл на 20%.
- Здание: игрок выбирает рецепт, запускает производство, забирает готовый товар. Входные ресурсы списываются при запуске.
- Апгрейд: 5 уровней, цена `baseCost * growth^(level-1)`, рост выхода и/или ускорение по данным конфига.
- Оффлайн: начисляются циклы животных и автособираемых грядок, максимум 2 часа; награда выдаётся после модального окна, x2 — только после подтверждённого rewarded.

## Платформенный lifecycle

- Инициализация SDK и чтение сохранения до игрового экрана.
- `ready()` — после загрузки ассетов и создания первого интерактивного кадра.
- `gameplayStart()` / `gameplayStop()` — при входе/выходе из gameplay, паузах, меню и рекламе.
- Rewarded — только по кнопке; награда только при подтверждении SDK.
- Interstitial — в естественных паузах: открытие зоны/значимая веха, не в первые 3 минуты.
- Pause/audio события платформы останавливают звук и gameplay.
- Сохранение: версия, миграция/нормализация, autosave 20 с, сохранение после значимых действий, pagehide/visibilitychange.

## Визуал и UI

- Cozy cartoon 2.5D: пастельное небо, парящий остров, мягкие формы, крупные читаемые объекты.
- Ассеты — собственные SVG-иллюстрации в единой палитре; предусмотрены Nano Banana промпты и pipeline замены на PNG/WebP.
- Canvas-based UI Phaser: верхний HUD, кнопки заказов/магазина/настроек, подсказки туториала, модальные панели.
- Touch targets не меньше 56 логических px, один тап на ключевое действие.
- Обратная связь: floating text, ready-пузыри, прогресс-бары, звуки, toast, мягкий shake при ошибке.

## Критерии готовности

1. Игра запускается локально и собирается `npm run build`.
2. Работают сбор урожая, посадка, заказы, апгрейды, животные, здания, помощники.
3. Работают сохранение/загрузка, оффлайн-доход, mock rewarded, пауза/звук.
4. Есть ru/en, адаптивный canvas, управление мышью и тачем.
5. Сервисы покрыты unit-тестами; сборка и тесты проходят.
6. Есть README, ассет-лист, Nano Banana промпты, image/audio pipeline, инструкции публикации.
